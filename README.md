# OUTERSTELLAR 🚀  
**Beyond standard media. One infinite hub.**

An all-in-one space-futuristic entertainment and utility hub built for seamless content consumption—no sign-ups, no tracking, and no accounts required.


---

## 📌 Overview

**OUTERSTELLAR** is designed to simplify your digital routine by aggregating essential everyday media into a single, high-performance Android command center. Built using modern Android development practices (Kotlin, Jetpack Compose, Media3/ExoPlayer, and Material 3), OUTERSTELLAR eliminates the hassle of managing dozens of standalone apps for entertainment and information.

---

## ✨ Features

* **📺 TV Hub**  
  Stream live IPTV channels and local MP4 videos powered by ExoPlayer with auto-hiding edge-to-edge desktop controls, smooth aspect ratio scaling, and built-in **Audio Boost**.
* **🎮 Game Zone**  
  Play native arcade mini-games right inside the app, featuring **Snake** (with wall-collision mechanics), **Tic Tac Toe**, and **Minesweeper**.
* **📰 News Feed**  
  Stay up to date with real-time news headlines pulled directly from top global RSS feeds (World, Tech, Sports, Entertainment) paired with instant push notifications (`POST_NOTIFICATIONS`) and Chrome Custom Tabs.
* **🎵 Music & Audio**  
  Enjoy background audio streams and local soundscapes through an intuitive built-in player interface.
* **⚙️ Customizable Settings & Dynamic Theme**  
  Configure storage caches, manage playback preferences, and enjoy a private, frictionless experience with seamless **Light, Dark, and System Default** theme scheduling.

## 🚀 Getting Started

### Prerequisites
* **Android Studio**: Jellyfish / Koala or newer recommended
* **JDK**: Version 17 or higher
* **Minimum SDK**: API 24 (Android 7.0)
* **Target SDK**: API 34+ (Android 14+)

### Building from Source
1. **Clone the repository:**
   ```bash
   git clone https://github.com/MindBLOWNProductions/Outerstellar.git
   cd Outerstellar
   ```
2. **Open in Android Studio:**
   * Open Android Studio, click **File > Open**, and select the project directory.
3. **Sync Gradle & Run:**
   * Allow Gradle to sync and download dependencies.
   * Select an emulator or physical Android device and click **Run** (`Shift + F10`).
